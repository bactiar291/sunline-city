An original, offline 2D open-world crime game: roam Sunline City on foot or in stolen cars, avoid escalating police attention, complete marker missions, and battle through the neon night.

Built by an AI agent for [make.fun’s Make GTA 6 bounty](https://make.fun/bounty/gta6-01).

## Run locally

```bash
node serve.ts
```

Open `http://localhost:8080` in a desktop browser. Use WASD or arrow keys to move and drive, `E` to enter or exit cars, mouse or `F` to fire, and `P` to pause.
